# ゆめはん 人物イラスト基準

## 基本ライン

012のイラストを、人物入りイラスト主体コンテンツの自社基準にする。

- 水彩線画、婦人誌の挿絵風。
- 対象読者は40代から50代女性だが、人物の見た目年齢を狭く固定しすぎない。基準画像程度の年齢感・雰囲気でよく、10代や幼い印象に見えない大人の女性にする。
- 若作り、未成年風、少女漫画風、アイドル風、強いアニメ風にはしない。20代から30代に見える場合でも、幼さや露出、軽すぎる雰囲気がなければ許容する。
- 肌をつるっと若く描きすぎず、自然な大人の表情、落ち着いた髪型、上品な普段着を基本にする。ただし、必要以上に老けさせない。
- 体型は細すぎず、現実感のある自然なバランスにする。
- キャラクターの存在感はあるが、商品や身体悩みより前に出しすぎない。
- 表情は少し豊かにしてよい。コミカルでも子どもっぽくしない。ユーモアは顔の若さではなく、しぐさ、姿勢、場面の間で出す。
- 服を着た自然な生活シーンにする。
- 顔アップ、下着姿、露出、胸元・ヒップ・股部分の強調は禁止。
- 体型比較、痩身効果、医療効果に見える表現は禁止。

## 使い方

イラスト主体コンテンツでは、生成前にこのフォルダを確認する。

`reference_mode=illustration_style` の場合、この `style_notes.md` を必ず読む。画像参照だけに頼らず、年齢感、露出制限、人物の存在感、禁止事項はこのテキストルールを優先する。

参照画像が若く見える、または生成結果が若く寄る場合は、「10代や幼い印象に見えない大人の女性」「若作り・未成年風禁止」を上位ルールとして扱う。現在の基準画像程度の年齢感であれば問題ない。

ただし、同じ構図、同じ服色、同じ部屋、同じ表情を繰り返さない。本文テーマに合わせて、場面、ポーズ、小物、季節、人物の距離感を変える。

実写風生成、商品画像生成、背景のみの生成では、このフォルダを参照しない。自社用人物イラストの基準としてのみ使う。
