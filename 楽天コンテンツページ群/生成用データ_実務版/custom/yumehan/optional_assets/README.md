# optional_assets

通常生成では、このフォルダ内の画像を参照しません。

ユーザーが明示した場合、または同ジャンルページの見た目差別化が必要な場合だけ参照します。

## フォルダ

- `backgrounds/`: 背景の雰囲気、室内、街、オフィス、玄関、旅行など。
- `usable_people/`: 使用許可済み人物画像。年代感や服装の参考に限定する。
- `textures/`: 布、紙、壁、光などの質感。
- `seasonal_props/`: 傘、コート、ニット、白シャツ、旅行バッグなど季節小物。
- `color_mood/`: 色味やトーンの参考。

## 注意

- 商品画像は入れない。
- 権利や肖像権が不明な人物画像は入れない。
- 下着姿、露出、顔アップ、身体悩みを直接見せる画像は入れない。
- 参照した画像をそのまま再現しない。
