# 画像・バナー生成プロンプト

## 基本方針

画像は、文章を読み進めてもらうための編集要素です。

商品ページ画像は使わず、コンテンツのテーマに合ったイメージ画像を生成します。

ただし、生成前には商品画像を必ず確認します。目的は商品写真の再現ではなく、商品カテゴリの誤認防止とイメージ展開です。商品画像から拾うのは、シルエット、丈感、ボリューム感、露出の程度、素材感の方向性、色味の傾向、使用シーンのヒントまでにします。正確な柄、ロゴ、商品ページ内の文字、サイズ表記、価格、モデルの顔や体型、商品写真の構図そのものは再現しません。

## images フォルダのルール

`images/delivery/` に入れるもの:

- 生成した生活イメージ
- コラムの世界観画像
- 章タイトル用画像
- 知識整理用バナー背景
- 比較・選び方バナー背景
- 知識系コンテンツ用の理解補助イラスト

`images/work/` に入れるもの:
- 生成元の背景画像
- `*_bg.*`
- 文字入れ前の個別生成画像
- 動画用の個別生成背景
- 標準TSVに出さない `*_points.jpg`

`images/work/generated_originals/` に入れるもの:
- AIで生成した文字なし画像の元データ
- 採用しなかったが、別ページや別バナーで流用できそうな生成画像
- 生成直後のファイル名では分かりにくい場合は、コンテンツ番号と短い役割名へリネームしたコピー

`images/` に入れないもの:

- 商品ページ画像
- 商品画像を合成した画像
- 商品名、価格、型番、パッケージ文字が読める画像
- 素材シート、3x3グリッド、複数画像をまとめた一覧画像
- 素材シートや一覧画像から切り出した画質劣化画像
- `contact_sheet`、`preview` などの確認用一覧画像

商品ページ画像を参照用に保存する場合は `data/product_reference/` に分けます。これは生成前の確認用であり、納品対象ではありません。リンク可能な商品紹介は、楽天の関連商品パーツで扱います。

## 画像ファイル名のルール

納品用画像は、コンテンツ番号を先頭に付けて短く管理する。

形式:

```text
{content_no}_{asset_role}.jpg
```

例:

```text
001_title.jpg
001_awareness.jpg
001_support.jpg
001_choice.jpg
001_comfort.jpg
001_closing.jpg
001_knowledge.jpg
```

ルール:

- コンテンツ番号は3桁にする。初回は `001`。
- ファイル名は半角英数字、アンダースコア、拡張子 `.jpg` を基本にする。
- 画像名に日本語、空白、長い説明文を入れない。
- `banner`、`image`、`final` など、なくても用途が分かる語は原則入れない。
- ページ冒頭のタイトル画像は `001_title.jpg` にする。
- 本文中の章画像は、`awareness`、`support`、`choice`、`comfort`、`closing` など短い役割名にする。
- 知識補助イラストは `001_knowledge.jpg` にする。
- 商品画像はこの命名ルールの対象外。楽天の商品パーツで扱う。
- 単独のサムネイル画像は標準では作らない。動画カバー用の画像が必要な場合は中間素材として扱い、納品画像やTSVには入れない。

## 画像生成ルール

- 納品画像と動画背景に使う画像は、必ず1用途1画像として個別生成する。
- 3x3グリッド、素材シート、複数画像を1枚にまとめた画像から切り出して納品画像や動画背景を作らない。
- 文字入れ前の個別生成画像は、後で流用できるため `images/work/` に保存してよい。
- 生成した画像はトークンを消費した制作資産として扱い、明らかな失敗画像を除いて `images/work/generated_originals/` に残す。
- コンタクトシート、プレビュー一覧、動画確認用一覧は納品物ではない。必要な確認が終わったら削除してよい。
- コンタクトシート、プレビュー一覧、素材シートを納品画像や動画背景の生成元にしない。
- 素材シートや一覧画像から切り出した画像は画質が劣化するため保存資産にしない。
- 画像制作の順序は「個別生成 -> 元画像保存 -> 役割名で配置 -> 文字入れ・リサイズ加工 -> delivery書き出し -> 動画生成 -> 確認用プレビュー」とする。
- 同一ページ内の章バナー、アクセント画像、ポイント画像、動画背景は、原則として1用途1元画像にする。同じ元画像を複数の納品画像へ使い回さない。
- ストーリー動画で同じ場面を意図的に続ける場合のみ動画背景の連続使用を許可する。ただし章バナーやアクセント画像として納品する画像は別画像を用意する。
- 画像生成後、`scripts/check_image_reuse.py` で同一ページ内と同一商品群の近似重複を確認する。
- コンタクトシート、サムネ一覧、動画プレビュー一覧は最後の確認用に限る。先に一覧を作って素材化しない。
- 個別生成した1枚画像を納品サイズや動画サイズへ合わせてトリミングすることは許可する。ただし、素材シート、コンタクトシート、サムネ一覧、動画プレビュー一覧から切り出さない。
- 納品画像や動画背景を、スクリプトで描いた簡易図形、プレースホルダー、抽象的な棒人間、単純なグラデーションだけで代替しない。
- コードで作るのは、文字入れ、リサイズ、トリミング、光彩、動画編集などの加工工程に限る。
- 背景そのものは、実写風生成画像、イラスト生成画像、またはユーザー指定の素材を個別画像として用意する。
- 背景に日本語テキストを入れない。
- ロゴ、透かし、架空ブランド名を入れない。
- 手元、人物の一部、暮らしのシーン、素材感を使い、イメージを明確にする。
- 季節感は、服装、光、室内小物、天気、街の空気で自然に出す。
- 顔や露出の強い身体表現は避ける。
- 通常コンテンツでは、タイトル画像、章バナー、アクセント画像、動画背景のいずれかに、最低1枚は人物の気配があるイメージを入れる。
- 人物入り画像は、後ろ姿、横姿、手元、半身、外出前の自然な所作を基本にする。
- 人物を入れる目的は、商品説明ではなく読者の生活シーンを具体化すること。顔を主役にせず、服を着た自然な場面にする。
- 下着姿、身体の悩みを直接見せる描写、顔のアップは禁止。
- 文字入れ用に、画像幅の40から55%を余白として残す。
- 抽象的な壁紙、単なるグラデーション、ぼけすぎた背景は禁止。
- 商品そのものをAIで再現しようとしない。

## 画像生成後の納品品質チェック

画像生成後、文字入れ、動画生成、TSV出力へ進む前に、必ず目視で採用可否を判断する。

このチェックは、ファイルが存在するか、サイズが合っているか、文字が切れていないかだけでは不十分。画像そのものが、楽天コンテンツページの読み物を支える納品品質に達しているかを確認する。

不採用にする画像:

- 簡易図形、棒人間、プレースホルダー、仮素材に見える。
- 実写風またはイラスト風など、企画で指定した画像テイストに達していない。
- テーマ、読者層、商品カテゴリと合っていない。
- 商品写真の精密再現、商品画像の混入、商品名、価格、型番、ロゴ、商品ページ内文字が見える。
- 人物が若すぎる、幼く見える、露出や身体の悩みが強調されている。
- 章バナー、アクセント画像、動画背景が同じ場面、同じ構図、同じ色味に寄りすぎている。
- 画像だけで医療効果、痩身効果、商品効果を断定しているように見える。
- 文字入れ後に読みづらい、余白設計が悪い、背景と文字の相性が悪い。

採用できる画像:

- 文字なしの状態でも、コラムのテーマや生活シーンを自然に連想できる。
- 実写風なら、写真として自然で、読み物ページのバナーに見える。
- イラスト風なら、企画で指定したテイストに合い、上品な読み物の挿絵に見える。
- ページ全体で並べた時に、単調すぎず、かつ世界観が破綻していない。
- 後入れ文字を載せても、主役モチーフと文字が喧嘩しない。

採用チェックの結果は `notes.md` に残す。

例:

```text
画像品質チェック: 問題なし
```

```text
画像品質修正: 020の章バナーが簡易図形に見えたため不採用。実写風プールサイド背景へ差し替え。
```

## 参照素材とカスタムフォルダ

共通ルールと、店舗独自の画像テイストは分けて管理する。

店舗独自の参照素材は `custom/{brand}/` に置く。共通ルールを他社へ渡す場合は、このフォルダを各社用に差し替える。

標準構成:

```text
custom/
  yumehan/
    reference/
      illustration_style/
        character/
        explanation/
      photo_style/
        lifestyle/
    optional_assets/
      backgrounds/
      usable_people/
      textures/
      seasonal_props/
      color_mood/
```

参照モード:

- `reference_mode=none`: 参照画像を使わない。
- `reference_mode=illustration_style`: 人物イラストの線、色、人物の存在感、表情の強さを参照する。
- `reference_mode=product_inspired_illustration`: 商品画像を参照し、形状や雰囲気だけをイラスト化する。
- `reference_mode=explanation_illustration_style`: 説明用イラストの余白、上品さ、簡潔さを参照する。
- `reference_mode=optional_background`: 背景の雰囲気だけを参照する。
- `reference_mode=optional_person`: 使用許可済み人物画像を、年代感、服装、雰囲気の参考として参照する。
- `reference_mode=optional_color_mood`: 色味やトーンだけを参照する。

画像・動画の制作依頼では、生成前に商品寄せレベルを必ず提示または確認する。ユーザー指定がない場合は、商品カテゴリ、単一商品か商品群か、特殊形状か、商品誤認のリスク、ページ間の差別化を踏まえて推奨レベルを決め、制作メモへ残す。

商品寄せレベル:

- `level_0_confirm_only`: 商品画像は確認のみ。画像には反映しない。
- `level_1_category`: 商品カテゴリが誤認されない程度に寄せる。
- `level_2_feature`: シルエット、丈感、透け感、素材感、色味の方向性など特徴を反映する。
- `level_3_product_mood`: 実商品に近い雰囲気の生成衣服や小物を出す。ただし商品写真そのもの、モデル、ロゴ、文字、価格、完全な柄再現は避ける。
- `level_4_special_product`: 特殊形状や通常カテゴリと大きく違う商品で、商品画像を強く参照する。ただし実商品画像は合成しない。
- `level_5_actual_product_photo`: 実商品画像そのものを使う。標準では納品画像や動画背景に使わず、楽天の商品リンク可能パーツ側で扱う。

実写風生成画像の標準は `reference_mode=none` とする。ユーザーが明示的に参照フォルダや参照画像を指定しない限り、`custom/`、`reference/`、`optional_assets/` の画像を参照しない。実写風画像は、同じ商品群でもページごとの差別化を優先し、場面、人物位置、余白位置、光、色味、小物を毎回設計する。

イラスト主体コンテンツの標準は `reference_mode=illustration_style` とする。ブランド別カスタムフォルダに人物イラストのリファレンスがある場合、基本テイストとして参照してよい。ただし、構図、ポーズ、服色、部屋、表情を毎回同じにしない。

`reference_mode=illustration_style` の場合は、生成前に `custom/{brand}/reference/illustration_style/character/style_notes.md` を必ず確認する。参照画像よりも `style_notes.md` のテキストルールを優先する。人物は基準画像程度の年齢感・雰囲気を基本にし、10代や幼い印象に見えない大人の女性として描く。若作り、未成年風、少女漫画風、アイドル風、強いアニメ風にはしない。20代から30代に見える場合でも、幼さや露出、軽すぎる雰囲気がなければ許容する。露出、下着姿、胸元・ヒップ・股部分の強調、性的印象は禁止する。キャラクターは読み物を助ける存在であり、商品や身体悩みより前に出しすぎない。

説明用イラストを作る場合は、必要に応じて `reference_mode=explanation_illustration_style` を使う。人物の魅力よりも、理解しやすさ、上品さ、誤解のなさを優先する。

商品シルエットや見た目が通常品と大きく違う場合は、特殊指示として `reference_mode=product_inspired_illustration` を使える。商品画像は `data/product_reference/` に置き、納品画像フォルダへ入れない。生成時は商品の形状、丈感、ふんわり感、色柄の方向性だけを参照し、商品写真そのもの、ロゴ、価格、サイズ表記、商品ページ内の文字は再現しない。水着や下着テーマでは露出や体のラインを強調せず、10代や幼い印象に見えない大人女性が着られる「雰囲気として近い衣服」として描く。

任意参照素材を使う場合は、参照目的をプロンプト内に明記する。例: 背景の雰囲気だけ、人物の年代感だけ、色味だけ、季節小物だけ。参照画像をそのまま再現しない。使用した参照フォルダと画像名は `notes.md` に記録する。

## 同一商品群での見え方重複防止

同じ商品群から複数のコンテンツを作成する場合、タイトルバナーと動画1シーン目は、同じ商品群の既存コンテンツと似すぎないようにする。

確認対象:

- `001_title.jpg` などのメインバナー
- 動画1シーン目の背景
- 章バナー、アクセント画像、動画用背景

避ける重複:

- 同じような部屋、同じような人物位置、同じような服色、同じような余白位置が続く。
- 毎回、左文字・右人物・白い部屋だけになる。
- 毎回、クローゼット前、窓辺、ベッドサイドなど同じ場面になる。
- 同じ商品群の記事なのに、ファーストビューの印象がほぼ同じになる。

差別化の方法:

- 場面を変える: クローゼット、洗面台、リビング、外出前の玄関、カフェ風のテーブル、仕事前の机、旅行準備、夜の支度など。
- 構図を変える: 人物右寄せ、人物左寄せ、手元中心、後ろ姿、小物中心、奥行きのある部屋、真上からの静物など。
- 光を変える: 朝の自然光、午後のやわらかい光、夜の落ち着いた室内光など。
- 色の印象を変える: ピンクベージュ、グレージュ、淡いグリーン、白木、チャコール小物などをローテーションする。
- 季節を変える: 春の薄手ブラウス、夏の明るい窓と冷房の室内、秋のニット、冬のコートや静電気を感じる玄関、梅雨の雨粒や傘などを使い分ける。
- 動画1シーン目はメインバナーと完全同一背景にしない。似た世界観でも、構図または場面を変える。

制作時は、同じ商品群の既存コンテンツを確認し、メインバナーと動画1シーン目の差別化メモを `notes.md` に残す。

同一商品IDまたは同一商品群の2本目以降では、メインバナーと動画1シーン目だけでなく、章バナー、ポイント画像、アクセント画像、動画背景も重複防止の対象にする。画像生成前に既存ページの `images/delivery/`、`images/work/` と動画プレビューを確認し、既存ページで使った場所、季節、時間帯、人物の有無、人物位置、視点、余白位置、小物、色味を棚卸しする。

新規ページでは、場所、季節、時間帯、人物の有無、視点、小物、色味のうち最低3つを既存ページから変える。特にアクセント画像は汎用的な「明るい室内」「クローゼット」「青空の街角」「椅子とバッグ」に寄りやすいので、同じ商品IDの直近ページで使われていた場合は避ける。

タイトル画像はページの第一印象になるため、章バナーより厳しく差別化する。同一商品IDまたは同一商品群のタイトル画像では、場所、人物の有無、人物位置、視点、余白位置、色味、小物のうち最低3つを既存ページから変える。

連続ページでは、同じ「背景カテゴリ + 人物位置 + 文字余白位置」の型を使い回さない。たとえば、直前ページが「明るい室内 + 右側人物 + 左文字」なら、次ページは人物なしの静物、手元中心、俯瞰、外出先、夜の室内、色味変更などへ振る。これは特定商材専用ではなく、下着、衣類、水着、介護用品などすべてのコンテンツで使う共通ルールとする。

同じ商品カテゴリでも、タイトル画像で主役にする要素を変える。商品や使用場所を毎回そのまま見せるのではなく、記事テーマに合わせて、体感、準備、時間、選び方、季節、外出前後、小物、読者の悩みなどから主役を選ぶ。直前ページが「使用中の場面」なら、次ページは「準備」「小物」「生活シーン」「余白のある静物」などに寄せる。

タイトル画像は、近似重複チェックがOKでも、同一商品群の直近タイトル画像と必ず目視で並べて確認する。画像ハッシュでは拾えない「第一印象が同じ」「構図テンプレートが同じ」場合は差別化不足とし、タイトル画像だけでも差し替える。

`notes.md` には必ず以下を残す。

- `既存ページで避ける要素: ...`
- `今回採用する差別化要素: ...`
- `画像差別化チェック: 問題なし` または `画像差別化修正: ...`

## 知識系イラストのルール

骨盤底筋、姿勢、冷え、静電気、素材、吸水構造など、エビデンスや構造理解があると読み手の納得感が上がるテーマでは、番外パーツとして線画イメージイラストを1枚作成してよい。

- 役割は、医学図解ではなく婦人誌コラムの理解補助。
- 写真バナーとは別枠で、本文中盤の知識説明セクション付近に差し込む。
- 商品訴求ではなく、読者が「何の話か」を直感的に理解するために使う。
- 線画、淡色、余白多め、文字なしを基本にする。
- 人体はリアルにしすぎず、やわらかいシルエットや抽象表現にする。
- 医療感、解剖図感、病院感、断定的な効能説明は禁止。
- 性的に見える表現、下半身や胸元へ視線を集める構図、身体部位の強調は禁止。
- 骨盤底筋、尿もれ、補整、体型などのテーマでは、該当部位に発光、線、丸、矢印、色面を重ねて直接示さない。
- 人物は服を着た自然な生活シーン、横姿、後ろ姿、手元、姿勢、歩く・座る・軽く整える動作で表現する。
- 下着姿、肌の露出、脚を大きく開いたポーズ、身体の悩みを直接見せる描写は禁止。
- 筋肉名や矢印などの文字入り図解にはしない。説明はページ本文側で行う。
- ポーズ解説画像を作る場合も、矢印は原則使わない。誤った部位指示や医療図解に見えるリスクを避けるため、番号付きの短い文字ラベルだけで説明する。
- 文字ラベルは「背すじを長く」「息を止めない」「肩の力を抜く」「無理なら休む」など、身体内部ではなく外側から見て分かる注意点にする。
- 小説風、コミカル系、季節コラム系など、雰囲気や物語で読ませる企画では原則使わない。

生成プロンプトでは、`line illustration`, `women's magazine editorial`, `soft minimal`, `no text`, `not medical anatomy diagram`, `fully clothed`, `non sensual`, `no body part emphasis` を明示する。

## イラスト主体コンテンツのルール

ユーザーから「イラスト主体」「イラスト主体の方法」などの指示がある場合は、ページ全体を写真風バナーではなく、水彩線画の誌面風コラムとして作成する。

イラスト主体コンテンツでは、指定がない限り `reference_mode=illustration_style` を使い、`custom/{brand}/reference/illustration_style/character/` の基準画像と `style_notes.md` を確認する。配布先の他社では、同じ場所に各社のイラスト基準を入れることで、その会社のテイストを基本にできる。画像だけでは年齢感や禁止事項がずれやすいため、`style_notes.md` の内容を生成プロンプトに明示的に反映する。

主な用途:

- 服のシルエット、布の落ち方、視線の集まり方などを説明するファッション知識系
- 骨盤底筋、姿勢、冷え、素材、静電気などをやわらかく説明する知識系
- 写真にすると身体表現が直接的になりすぎるテーマ
- 読み物としてやわらかい雰囲気を作りたいテーマ

作成する画像:

- タイトル用イラスト
- コラムポイント用イラスト
- 理由説明イラスト
- 視線や印象の説明イラスト
- 布、素材、服の落ち方を見せるイラスト
- 選び方イラスト
- まとめ用イラスト

イラスト主体コンテンツでは、本文冒頭または動画直下に置ける「コラムポイント」用の正方形画像を必ず1枚作成する。

- ファイル名は `{content_no}_points.jpg` を基本にする。
- サイズは `1200 x 1200`。
- 3項目の箇条書きを後入れ文字で配置する。ユーザーが指定した場合のみ2項目または4項目にする。
- 見出しは「このコラムのポイント」を基本にする。
- 各項目の先頭は動画と同じく半角の山括弧風記号「›」で統一する。
- 文章は本文の要約ではなく、読み進めたくなる短い見出しにする。
- 背景イラストは、画像幅の45から60%を文字が乗る余白として確保する。
- 生成画像自体には文字、矢印、丸囲み、ラベルを入れない。
- 文字は必ず後入れし、改行位置と可読性を確認する。
- `points.jpg` は原則として動画内の目次、制作確認用の管理素材とし、標準の楽天本文TSVには入れない。
- `rakuten_parts_plan.csv` で管理する場合は `part_type=points_image` とし、通常の章バナーを表す `part_type=banner` と混ぜない。
- ユーザーが「ページ内にもポイント画像を入れる」と明示した場合だけ、TSV出力対象にする。

表現ルール:

- `refined watercolor and thin ink line illustration` を基本にする。
- 婦人誌、女性向けファッション誌、生活コラムの挿絵のように見せる。
- 写真の代替ではなく、読み物の理解を助ける「やわらかい図解」として扱う。
- 画像内に説明文字、矢印、丸囲み、ラベル、記号を入れない。説明は後入れ文字と本文で行う。
- 人物を入れる場合は、全員服を着た自然な生活シーンにする。
- 顔のアップ、下着姿、露出、胸元・ヒップ・股部分の強調を避ける。
- 体型のビフォーアフター、痩身効果、医療効果に見える比較は禁止。
- 比較風の画像を使う場合も、体型比較ではなく「布の張り」「服の落ち方」「シルエットの見え方」の説明として扱う。
- バスト、補整、尿もれ、骨盤底筋など繊細なテーマでは、身体部位へ視線を集める構図を避ける。
- 画像幅の40から55%を余白として残し、後入れ文字が人物や主役モチーフに重ならないようにする。
- 色は、アイボリー、ベージュ、淡いグレー、くすみピンク、ミュートグリーン、チャコール小物などを中心にする。
- 商品画像、商品名、価格、型番、パッケージは入れない。

動画への展開:

- 動画背景も同じイラスト素材を使い、ページ全体の見え方を統一する。
- 標準動画は写真風と同じく `toc_cm` の「動く目次CM」として作る。
- イラスト主体で、主人公、葛藤、心の声、小さなオチがある企画は `video_style=illustrated_story_cm` を使ってよい。
- `illustrated_story_cm` は、婦人誌の挿絵が少し動く短いコラムCMとして扱い、本格的な漫画表現にはしない。
- 生成画像には吹き出し、コマ割り、集中線、漫画記号、日本語テキストを入れない。必要な文字は動画編集時に後入れする。
- タイトル、ポイント、章コピーを短く見せ、イラスト自体に説明を詰め込まない。
- 終了ロゴ、BGM音量、MP4カバー画像埋め込みは通常ルールと同じ。

採用チェック:

- 女性向けインナーショップの読み物として上品に見えるか。
- 体型否定、性的表現、医療断定、痩身効果の誤認がないか。
- 文章なしでもテーマを連想できるが、画像だけで断定説明していないか。
- 写真風コンテンツと並んだ時に差別化できるか。

## イラスト生成後チェック

知識系イラストは、生成後に必ず違和感チェックを行う。

以下に1つでも当てはまる場合は採用しない。

- 性的、フェティッシュ、身体部位の強調に見える。
- 下半身、胸元、ヒップ、股部分へ視線が集まる。
- 医療図、解剖図、症状説明図のように見える。
- 矢印、丸囲み、発光などで身体内部や特定部位を示している。
- 悩みを直接描写しすぎて、読者が気まずく感じる。
- 商品効果を断定しているように見える。
- 楽天の女性向けインナーショップに置いたとき、上品な読み物の挿絵として浮く。

採用基準:

- 婦人誌や生活コラムの挿絵として自然に見える。
- テーマを連想できるが、身体部位を直接説明しない。
- 商品販売よりも、読み物の理解補助として見える。
- 読者が安心してスクロールできる。

## 文字入れの方向性

画像内の文字は、用途により2種類を使い分ける。

- 見出しタイトル型: 本文バナー、章タイトル画像向き。短く強い見出しを入れる。
- 導入文分割型: 動画向き。1文を意味の切れ目で2から3行に分け、読みたくなる余韻を作る。

見出しは明朝系を基本にし、女性用インナーショップらしい上品さを優先する。

## バナー文字の改行ルール

バナーの文字は、自動折り返しだけで決めない。

- タイトルは原則1行表示にする。
- 1行で読みにくい場合のみ、意味の切れ目で2行にする。
- 句点 `。`、読点 `、`、中黒 `・`、閉じ括弧だけを単独行にしない。
- `を`、`に`、`へ`、`が`、`は` などの助詞だけを不自然に孤立させない。
- 文章の末尾の `。` は、必ず直前の語と同じ行に入れる。
- 改行候補は、読点、助詞の後、対句の境目、意味のまとまりで判断する。
- 横長バナーでは、短いタイトルなら1行のまま横に伸ばす。
- どうしても収まらない場合は、文字サイズを5から10%下げるか、コピー自体を短くする。

良い例:

```text
尿漏れ対策を、ふつうの準備に。
```

```text
尿漏れ対策を
ふつうの準備に。
```

悪い例:

```text
尿漏れ対策を、ふつうの準備に
。
```

## バナー標準

- メインタイトルバナー: `1600 x 900`
- 通常コンテンツの章区切りバナー・コラムポイントバナー: `1600 x 520`
- 正方形画像は、アクセント用シチュエーション画像、商品ページ差し込み用の独立画像、またはユーザーが明示した場合に限る。
- イラスト主体コンテンツで、本文冒頭や動画直下に大きく見せる「コラムポイント用イラスト」を作る場合のみ、例外として `1200 x 1200` を使ってよい。
- 通常コンテンツでは、イラスト主体用の正方形ポイント画像ルールを混在させない。
- 背景は写真風の生活イメージ
- 文字は後入れ
- 文字が載る場所を最初から設計する

## アクセント用シチュエーション画像

通常コンテンツでは、ページ構成を崩さない範囲で、文字入れを前提にしないアクセント用シチュエーション画像を1から2枚入れてよい。

アクセント画像は人物なしでもよい。ただしページ全体で人物の気配が1枚もない場合は、アクセント画像、章バナー、動画背景のいずれかを、手元、後ろ姿、横姿、半身、外出前の自然な所作に変更して補う。

役割:

- 文章が続いた後の息継ぎ
- 同じ室内・クローゼット・後ろ姿に寄りすぎることの防止
- 読者の生活シーンを広げる雑誌の挿入写真
- 商品特性から連想される気分、外出、仕事、季節、街の空気を見せる

標準:

- サイズは `1200 x 1200`
- 文字入れを前提にしない
- 日本語テキスト、ロゴ、商品名、価格、型番、パッケージは入れない
- 章タイトル画像やコラムポイント画像として扱わない
- 1ページにつき1から2枚まで
- ファイル名は `{content_no}_accent_01.jpg`、`{content_no}_accent_02.jpg` を基本にする

使えるシーン例:

- 青い空の街の風景
- オフィスのデスク
- 公園のベンチ
- カフェの窓辺
- 駅へ向かう朝
- 旅行前のバッグ
- 雨の日の玄関
- 冷房の効いた夏の室内
- ニットを着る秋冬の支度
- 静電気が気になる冬の玄関
- 衣替え中のクローゼット
- 洗濯物が揺れるベランダ
- 図書館や本のある机
- 花屋の前、散歩道

季節別の画像案:

- 春: 明るい窓辺、薄手ブラウス、衣替え中のクローゼット、通勤前の玄関
- 夏: 冷房の効いた室内、白いシャツ、日差しのある街、旅行前のバッグ
- 梅雨: 傘、雨粒のある窓、湿気を感じる洗面台、乾きにくい洗濯物
- 秋: ニット、落ち着いた午後の光、読書やカフェ、重ね着の支度
- 冬: コート、静電気を感じる玄関、暖かい室内光、長時間移動のバッグ
- 年末年始: 帰省前の荷造り、家族行事の支度、移動前の駅、親の家へ向かう外出感

季節感は1ページ内で入れすぎない。タイトル画像、章バナー、アクセント画像、動画背景のどれか1から2箇所に留め、本文のテーマより季節小物が目立たないようにする。

配置ルール:

- TSV標準順序は崩さない。
- `タイトル画像 → メインタイトル → 動画 → 動画下本文 → 小タイトル → バナー → 本文 → 関連商品` の流れを維持する。
- 標準では `points.jpg` を本文パーツに入れない。動画内で「このコラムのポイント」を見せているため、ページ本文側で重複させない。
- TSV生成後に、小タイトル直下へ画像が2枚連続していないか確認する。ポイント画像と章バナーが連続している場合は、ポイント画像を削除するか `part_type=points_image` に変更して標準TSVから除外する。
- アクセント画像を入れる場合は、本文ブロックの後、次の小タイトルの前に入れる。
- 章区切り用の `1600 x 520` バナーの代替にはしない。
- 近い商品群でページが続く場合、アクセント画像の場面を変えてページごとの印象差を作る。
- `rakuten_parts_plan.csv` では `part_type=accent_image`、`placement=after_body`、`after_section=章番号` を指定する。
- `placement` と `after_section` を持たない既存の通常バナーは、従来通り章へ順番に割り当てる。アクセント画像ルールで既存ページの標準バナー配置を変えない。
- 章バナーのテーマが特定の章に強く対応する場合は、通常バナーにも `part_type=banner`、`placement=before_body`、`after_section=章番号` を指定する。
- TSV生成後に、各章の `小タイトル → 画像 → 本文` が自然につながるかを確認する。季節画像が季節以外の章に入る、まとめ画像が中盤に入りすぎるなどのズレは修正する。
- 関連商品は1商品IDにつき1行で出力する。貼り付け内容には商品IDのみを入れ、商品名、説明、role、noteは混ぜない。
