# 音楽生成プロンプト

## 基本方針

動画と一緒に短いBGMを生成します。

外部楽曲を使わず、ページのジャンルに合わせた短いオリジナル音源にします。

音なしでも成立する動画にしつつ、BGMは小さすぎない音量にします。

音量基準:

- BGMは音量を感覚値で指定せず、ラウドネス値で管理する。
- 標準BGMの目標値は `Integrated loudness: -33 LUFS` とする。
- 許容範囲は `-34 LUFS から -32 LUFS` を基本にする。
- True peak は `-9 dBTP 以下` を上限値にし、音割れや急なピークを避ける。
- 2026-09-03に確認した基準動画の音声は `Integrated loudness: -32.8 LUFS`, `True peak: -21.8 dBFS`。
- 基準音声は `references/audio/standard_bgm_ref.wav` に置き、迷う場合はこの音量感に合わせる。
- 生成後は可能な限り `ebur128` または同等のラウドネス測定で確認する。
- 音量調整だけを行う場合は、映像は再エンコードせず、音声のみ正規化してよい。

FFmpegで正規化する場合の標準設定:

```text
loudnorm=I=-33:LRA=7:TP=-9
```

## ジャンル別イメージ

### apparel_soft

下着、インナー、アパレル向け。

上品、やわらかい、ルックブック風、軽いリズム。

### beauty_clean

肌ざわり、清潔感、敏感肌、美容寄り。

透明感、清潔、軽さ、明るい余韻。

### senior_care

介護用品、高吸水、シニア向け。

落ち着き、安心感、ゆっくり、説明的すぎない。

### urban_column

補正下着、本音コラム、服のライン系。

都会的、雑誌的、テンポは `92から112 BPM`。

### season_bright

夏、冷感、季節雑貨、イベント系。

明るい、軽快、前向き、派手すぎない。

## 注意

- 楽天ページ上では再生環境により音が出ない場合がある。
- BGMは補助であり、映像と文字だけで意味が伝わるようにする。
