# サムネイル画像生成プロンプト

## 役割

サムネイル画像は、楽天コンテンツページの表紙画像として作成する。
ページ上部、楽天市場内のトピックス枠、検索エンジンの検索結果で表示されるため、本文中バナーよりも「一瞬で内容が伝わること」と「縮小時の可読性」を優先する。

## サイズ

- 推奨サイズ: 1600 x 900 px
- 横長 16:9
- 重要な文字や人物は端に寄せすぎない

## 基本方針

- 商品画像は使わない。
- 商品そのものをAIで再現しない。
- 生成した生活イメージ画像を使う。
- 読み物コンテンツのテーマが1秒で伝わる構図にする。
- セール画像、商品カタログ画像、商品ページ誘導バナーに見せない。
- 医療感、深刻さ、不安をあおる表現を避ける。
- 女性用インナーショップらしい、清潔で上品な表紙感を優先する。

## 構図

- 文字スペースを画像幅の40から50%確保する。
- 文字は左側または中央左を基本にする。
- 生活イメージ要素は右側または背景側に配置する。
- 人物の気配、手元、服、バッグ、部屋、素材感、外出前の準備など、テーマを連想できる要素を使う。
- 背景は明るく、雑誌の表紙や特集扉のように見せる。
- 背景に読める文字、ラベル、ロゴ、パッケージを入れない。
- ぼかしすぎない。検索結果で小さく見ても雰囲気が分かる解像感を保つ。

## タイトル文字

- 原則としてコンテンツタイトルを入れる。
- 長いタイトルは、意味を保った短縮版にしてよい。
- 最大3行まで。
- 1行ごとの文字数を短くする。
- 主キャッチを最も大きく、副キャッチは主キャッチの70から85%の文字サイズにする。
- 主キャッチと副キャッチの文字サイズ差は30%以内にする。
- 本文のような小さい説明文は入れない。
- 句読点だけを単独行にしない。
- 助詞だけを不自然に孤立させない。
- 検索結果で縮小されても読める太さとサイズにする。

## タイトル分解

長いタイトルは以下の構成に分ける。

- 主キャッチ: クリック理由になる短い言葉。
- 副キャッチ: 記事のテーマや読み物としての方向性。
- カテゴリ補足: 必要な場合のみ、商品カテゴリや選び方の軸。

例:

```text
尿もれ対策を
ふつうの準備に。

吸水ショーツの新しい考え方
```

## フォント

- 明朝系を基本にする。
- 太いゴシック、チラシ風、セール風フォントは避ける。
- 上品、清潔、読み物感、婦人誌の特集扉感を優先する。

## 文字色と装飾

- 文字色は1枚の中で統一する。
- 明るい背景では濃茶、チャコール、黒系文字を基本にする。
- 暗い背景では白、生成り文字を基本にする。
- 濃色文字には白の柔らかい拡散を使う。
- 白または淡色文字には黒または濃グレーの柔らかい拡散を使う。
- 背景に十分な余白があり文字が明確に読める場合は、拡散なしでもよい。
- 太い縁取り、黒ベタ枠、帯、ステッカー風加工は禁止。
- 光彩は細いフチではなく、背景となじむ広く薄い空気感にする。

## 生成手順

1. AI画像生成では、文字なしの生活イメージ背景を作る。
2. 背景は1600 x 900にトリミングできる構図にする。
3. 日本語タイトルは画像生成に任せず、後処理で入れる。
4. 後処理で明朝系フォント、文字色、拡散、改行を調整する。
5. 生成後、縮小表示でも読めるか確認する。

## 優先順位

1. 縮小時の可読性
2. クリックしたくなる表紙感
3. コンテンツテーマの即時理解
4. 読み物としての期待感
5. 楽天・検索結果内での明るさと清潔感
