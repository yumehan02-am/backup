# 動画生成プロンプト

## 動画の役割

動画は商品説明動画ではなく、楽天コンテンツページのタイトルバナー直下に置く「動く目次CM」として作成する。
本文を読み進めたくなるように、コラムの要点・問いかけ・意外性を短く見せる。

商品画像、商品名、価格、型番、販売訴求は原則として動画内に入れない。

## 動画スタイル

動画は1ページにつき1本を基本にし、企画段階で決めた `video_style` に従って作る。

- `toc_cm`: 標準。電車の吊り広告、婦人誌の特集予告、雑誌CMのように、コラムの問いやポイントを短く見せる。
- `illustrated_story_cm`: イラスト主体でストーリーまたはコメディ要素がある企画向け。主人公の小さな葛藤、心の声、視点の転換、現実的な着地を、短い動画マンガ風に見せる。

`illustrated_story_cm` は、ユーザーの明示がなくても、タイトル案の `column_pattern` が `comic_first_person`、`failure_story`、`short_story` で、イラスト主体または商品寄せイラストの企画なら標準候補にしてよい。知識整理、比較、Q&A、教科書型では原則 `toc_cm` を使う。

`illustrated_story_cm` は本格的な漫画ではなく、婦人誌の挿絵が少し動く短いコラムCMとして扱う。吹き出し、コマ割り、強い集中線、漫画記号を標準では使わない。文字は生成画像内に入れず、動画編集時に後入れする。

基本構成:

1. 主人公の願い、または悩み。
2. 小さな引っかかり、ためらい。
3. 心の声やコミカルな気づき。
4. 視点の転換。
5. 現実的な準備や選び方。
6. 静かな着地とロゴアウトロ。

サムネイルは、途中の変な表情や未読の文字が出ないよう、専用カバー画像を埋め込む。候補は、タイトルまたはポイントが読みやすく、主人公とテーマが自然に見えるフレームにする。

## 標準出力形式

新規作成する動画は、楽天アプリでの見え方を優先し、縦長動画をデフォルトにする。

- 標準動画: `720 x 960` の縦長MP4。
- 横長または正方形動画は、ユーザーから明示がある場合、または別用途で必要な場合のみ追加作成する。
- 動画用の背景画像は `1200 x 1200` の正方形で作成する。
- 正方形背景の中央を基準に、720 x 960へ切り出して動画化する。人物や主役モチーフが切れる場合は、切り出し中心を左右80px以内で調整する。
- 背景生成時点では、左右端に重要な被写体や文字入れ予定の余白を寄せすぎない。
- 文字は動画編集時に後入れし、中央安全領域内へ配置する。

## 基本トーン

- 電車の吊り広告
- 婦人誌の特集予告
- 雑誌CM
- 映画の導入
- コラムの予告編

## 背景画像

1シーンにつき1枚、専用の生成背景を用意する。
商品ページ画像は使わない。

- 背景素材の標準サイズは `1200 x 1200` の正方形。
- 縦長動画に使う場合も、背景生成は正方形のまま行う。
- 720 x 960へ切り出した際に成立するよう、主役の被写体は中央540px以内に収める。
- 壁紙風・抽象背景だけにしない
- コラム内容を連想できる生活イメージにする
- 手元、服、部屋、外出準備、素材感などを使う
- 季節感は背景の光、服装、小物、天気で自然に出す。季節を入れる場合も、商品説明ではなくコラムの空気を作るために使う。
- 季節案を使う場合は、春の薄手服、夏の冷房や日差し、梅雨の雨、秋のニット、冬のコートや静電気、年末年始の移動準備などから、本文テーマに合うものを1から2シーンだけ選ぶ。
- ページ全体の人物気配ルールを満たす。タイトル画像、章バナー、アクセント画像のいずれにも人物の気配がない場合は、動画背景のうち最低1シーンに人物の気配を入れる。
- 6シーン構成で人物の気配を入れる場合は、1から2シーンまでにする。
- 顔のアップ、下着姿、露出、体型悩みの直接表現は避ける
- 文字を入れる余白をあらかじめ作る

## 同一商品群でのシーン1重複防止

同じ商品群で複数のコンテンツ動画を作る場合、動画の1シーン目は過去コンテンツと似すぎないようにする。

- 1シーン目は動画の第一印象なので、同商品群の既存動画と場面、人物位置、余白位置、色味を確認する。
- 同じ商品群の記事で、毎回「明るい白い部屋、右側に女性、左側に文字」だけにしない。
- メインバナーと動画1シーン目も完全同一背景にしない。
- 似た世界観にする場合でも、場面、構図、光、季節感、小物のどれかを明確に変える。

ローテーション例:

- クローゼット前で服を選ぶ
- 洗面台で朝の身支度
- 玄関で外出準備
- 机とノートで自分の体を考える
- リビングで軽く姿勢を整える
- 旅行前にインナーを準備する
- 夜、明日の服を整える

制作時は、動画1シーン目の差別化意図を `notes.md` に1行で記録する。

## テキスト内容

動画内の文章は本文の丸写しではなく、読みたくなる短いコピーにする。

良い例:

```text
着るだけで痩せる？
それ、ありえません。
```

```text
でも、服の見え方は
整えられる。
```

避ける例:

```text
商品は終盤でふわっと見せる
```

```text
この動画では補正下着について説明します
```

## タイトルシーン固定ルール

- 1シーン目は5.0から6.0秒にする。
- 開始0.3から0.5秒は文字を出さず、背景だけを見せる。
- その後、キャッチコピーを一文字ずつ表示する。
- 2行に分ける場合は、同じフォント、同じサイズ、同じ色にする。
- 2行目を最初から表示しない。
- 文字が1文字だけ静止して見える時間を作らない。
- 全文表示後、0.8から1.2秒ほど余韻を残す。

## ポイントシーン固定ルール

「このコラムのポイント」は、各動画で流用しやすい共通パーツとして扱う。

推奨:

```text
このコラムのポイント
› できること
› できないこと
› 続けやすい選び方
```

- 「このコラムのポイント」は最初から表示する。
- その下に3行のポイントを1行ずつ表示する。ユーザー指定がある場合のみ2行または4行にする。
- 各ポイントの先頭は、基本的に半角の山括弧風記号「›」で統一する。
- 数字、中黒、矢印、アイコンを同じシーン内で混在させない。
- 「›」は本文の85から95%のサイズ、または不透明度70から85%にして、アパレル誌の目次のように見せる。
- ポイントは本文の小見出しと内容が一致する言葉にする。

避ける表現:

```text
このコラムのポイントは、少量の不安との付き合い方。
```

## 改行ルール

- 句点「。」、読点「、」、中黒「・」だけを単独行にしない。
- 助詞だけで行を終えない。例外はタイトルとして一般的な定型句、またはユーザー指定コピーを維持する場合に限る。
- 2行にする場合、意味の切れ目で分ける。
- 上下行の文字サイズはそろえる。
- 読みにくい場合は、動画尺を伸ばすか文章を短くする。

## 縦長動画の文字ルール

楽天アプリ向けの縦長動画では、動画内コピーを「読む文章」ではなく「見る見出し」として扱う。

- 動画サイズは原則 `720 x 960`。
- 楽天アプリ表示では、縦方向より横方向のトリミングリスクを優先して考える。
- 文字は中央寄せ、または中央配置の左揃えブロックにする。
- 文字は中央600pxの安全領域内に収める。
- 見た目の余白を残すため、通常の推奨文字幅は500から540pxにする。
- 縦方向は基本的にトリミングされにくいため、中央に詰め込みすぎず、上下の余白を活かして配置する。
- タイトル、本文コピー、ポイントの行間は、使用フォントサイズの1.25から1.6倍にする。
- 上80px、下80pxは最低余白として残す。
- 重要コピーを左右端に置かない。
- シーン1は、短い行を中央に積む縦組み風を許可する。
- シーン2以降は、中央寄せ横書きを基本にする。
- ポイントシーンは、見出しを中央、3項目は左揃えブロックにする。矢印「›」の位置をそろえる。
- 縦長動画では、句点「。」と読点「、」を原則外す。
- 意味の切れ目は句読点ではなく改行で表現する。
- 疑問符、引用符、中黒など、コピーの意味や読みやすさに必要な記号は残してよい。
- 本文、横長バナー、ページ用サムネイルでは通常どおり句読点を使ってよい。

## 文字装飾ルール

文字装飾は、文字色と背景の組み合わせで決める。
ただし、他の処理を入れる場合は光彩を外し、背景ごとに1種類だけ選ぶ。
ドロップシャドウ、光彩、半透明フチを同時に重ねない。

文字色は1シーン内で固定する。
動画の途中で背景がパン、ズーム、クロスフェードしても、同じシーン内で黒文字から白文字、または白文字から黒文字へ切り替えない。
文字色はシーン開始時、または代表フレームの文字配置エリアで決定し、そのシーンの最後まで維持する。

動画の処理負荷を下げたい場合は、文字そのものを毎フレームぼかすのではなく、文字の直下に行単位の薄い光彩レイヤーを置く。
この場合も光彩は文字より下のレイヤーに置き、2行目の光彩が1行目の文字にかぶらないよう、光彩をすべて描いてから文字を描画する。
行末の句点、読点、中黒、感嘆符、疑問符、閉じ括弧などは光彩サイズの計算から除外する。句読点自体は通常どおり表示する。
これは句読点だけで光彩の幅が不自然に広がることを避けるためのルールとする。

基本:

- 文字本体の不透明度は94から100%にする。
- 黒、濃茶、濃グレーなど濃色文字の場合は、白の拡散光彩を使う。不透明度は12から24%、ぼかし半径は文字サイズの0.7から1.2倍を標準にする。
- 白、生成り、淡色文字の場合は、黒または濃グレーの拡散光彩を使う。不透明度は14から28%、ぼかし半径は文字サイズの0.7から1.2倍を標準にする。
- 背景の余白が十分で文字が明確に読める場合は、拡散なし、またはごく薄い影だけでもよい。
- 光彩は細い縁取りに見せない。狭く濃い光彩ではなく、広く拡散させる。
- 背景が複雑な場合でも文字が読めるよう、拡散光彩の透明度を調整する。薄すぎて効果が見えない状態にしない。
- 光彩は「見える枠」ではなく、背景となじむ空気感として使う。
- 太い白フチは禁止。
- 文字がステッカーのように見える加工は禁止。
- 婦人誌・アパレル誌の紙面に自然に印刷されたように見せる。

背景別の選び方:

- 明るく余白が多い背景: 濃色文字 + 白の拡散光彩。不透明度12から18%、ぼかし半径は文字サイズの0.7から1.0倍。
- 明るいが柄や服の質感が多い背景: 濃色文字 + 白の拡散光彩。不透明度18から24%、ぼかし半径は文字サイズの0.9から1.2倍。
- 暗い背景: 白または生成り文字 + 黒または濃グレーの拡散光彩。不透明度14から22%、ぼかし半径は文字サイズの0.7から1.0倍。背景に十分な余白がある場合のみ拡散なしを許可する。
- 暗く複雑な背景: 白または生成り文字 + 黒または濃グレーの拡散光彩。不透明度22から28%、ぼかし半径は文字サイズの1.0から1.2倍。
- 明暗差が大きい背景: 装飾を強くせず、文字位置を余白側へ移動する。

英語プロンプトに入れる場合:

```text

The glow must be diffused and natural, not a tight visible outline.
For busy backgrounds, make the diffused glow slightly more opaque so the text remains readable.

subtle drop shadow, thin semi-transparent outline, or very soft glow.
Do not combine multiple effects.

```

## 演出パターン

複数パターンを組み合わせ、全シーンが同じ動きにならないようにする。

- タイトルの一文字ずつ表示
- ふわっと表示
- 横からスライド
- 写真のゆるいパン
- ゆるいズーム
- 1行ずつ表示
- 余韻を残すフェード

## 背景モーションルール

背景は静止画に見えないよう、各シーンにパンまたはズームを必ず入れる。
ただし、文字の可読性を妨げるほど速くしない。

- パンは最低40px、標準60から90px。
- ズームは最低3%、標準4から7%。
- タイトルシーンはゆっくりズームインを基本にする。
- 共感シーンは横パン、知識シーンは斜めパン、まとめシーンはズームアウトなど、シーンごとに動きを変える。
- ポイントシーンは読みやすさを優先し、パン40から60px、またはズーム3から4%に抑えてよい。ただし完全な静止にはしない。
- 微細な揺れは禁止。
- パン、ズームはイージングを使い、整数丸めによるカクつきを避ける。
- 背景の動きは文字アニメーションとは別に滑らかに処理する。

## シーン切り替えルール

- 連続するシーンで同じ背景を使わない。
- 同系統の背景が続く場合は、構図、被写体位置、明るさ、動き方を変える。
- 急な暗転を避ける。
- 0.25から0.45秒の短いクロスフェードを使う。
- クロスフェードは背景だけに適用し、前シーンの文字を次シーンへ持ち越さない。
- 背景が似ている場合は、テキスト演出だけでなくパン方向やズーム量も変える。

## 終了フェード・ロゴルール

動画の最後は、急にブツっと切らず、白または生成り色へフェードアウトして終える。

共通ロゴ素材:

```text
楽天コンテンツページ群/ゆめはんオリジナル商品マークB.png
```

- 最終シーンの最後0.9から1.2秒で、映像を白または生成り色へフェードする。
- BGMも同じタイミングでフェードアウトする。
- フェード後、白背景に店舗ロゴを0.8から1.5秒ほど静かに表示する。
- ロゴは画面中央、横幅の30から40%で配置する。
- ロゴは0.3から0.5秒かけてふわっと表示する。
- ロゴの背景は白または生成り。黒背景、急な暗転、強い販売訴求は禁止。
- ロゴ終了後も急停止に見えないよう、最後に0.2から0.4秒の余韻を残す。
- 商品名、価格、セール文言は終了ロゴシーンに入れない。
- ロゴは毎回生成し直さず、共通ロゴ素材を後入れで配置する。
- ロゴを動画背景やAI生成画像に混ぜ込まない。文字崩れやブランド崩れを避けるため、必ず編集工程で合成する。

## MP4サムネイル埋め込みルール

楽天側で動画の途中フレームがサムネイルとして表示される場合があるため、動画本体の演出は大きく変えず、MP4のメタデータとしてカバー画像を埋め込む。

- 埋め込む画像は、原則としてページ登録用サムネイル、または「このコラムのポイント」が読みやすく見える専用サムネイルにする。
- 商品画像、商品名、価格、型番、セール訴求をサムネイル画像に入れない。
- カバー画像は `images/delivery/xxx_thumbnail.jpg` を基本にする。移行前ページでは `images/xxx_thumbnail.jpg` も許容する。
- MP4には編集工程で `attached_pic` として画像を追加する。
- 楽天がMP4内サムネイルを採用しない可能性はある。その場合、動画側の構成は無理に変更せず、楽天側の自動抽出に任せる。
- 動画内の特定シーンをサムネイル用に長時間静止させる対応は、必要になった場合のみ検討する。

## 推奨尺

- 18から24秒
- 6シーンを標準にする。内容量により5から7シーンまで許可する。
- 1シーンあたり3から4秒
- タイトルシーンだけ5から6秒まで許容
