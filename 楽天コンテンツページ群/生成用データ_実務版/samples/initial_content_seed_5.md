# 初期コンテンツ企画 5件

この5件は、正式制作前に選別しやすいように作った初期データです。

共通ルール:

- 目的は読み物 + SEO + 商品紹介。
- セール訴求ではなく、役立つ内容を優先。
- 商品紹介は後半に自然につなげる。
- 動画はタイトル直下の「動く目次CM」。
- 動画には商品画像・商品名・価格・型番を原則入れない。
- `images/` には商品画像を入れない。
- 商品画像は `product_images/` と楽天のリンク可能な商品パーツで使う。

## 1. 尿もれ対策を“こっそり”から“ふつうの準備”へ｜吸水ショーツの新しい考え方

- スタイル: 本音コラム
- カテゴリ: 軽失禁・吸水ショーツ
- 読者ニーズ: 外出や日常の少量の尿もれが気になる
- コンセプト: 尿もれ対策を恥ずかしいものではなく、外出前の自然な準備として捉え直す読み物。
- 小見出し: 「ふつうの下着感覚」で備える / 20cc・30ccはどんな日向きか / パッドと吸水ショーツの使い分け / 外出前の安心を増やす選び方
- 動画コピー: こっそり悩む朝に / ふつうの準備という選択 / このコラムのポイント
- AI仮選定商品ID: `wtk-f-pw6c30b` `wtk-f-pw6c30` `oassh40b` `upbtk30` `oassh40`
