# 痩せてからプールに行くつもりが、まだ水着を買えていない話

ジムに通いたい。できればプールがいい。

膝にもやさしそうだし、汗だくになる感じも少なそう。水中ウォーキングなら、運動が得意ではない私にも始められる気がします。

問題は、プールに入るには水着になる必要があることです。

ここで頭の中に、なかなか手ごわい理屈が出てきます。

痩せるためにプールへ行きたい。けれど、水着になるには先に痩せたい。

この輪っか、どこで切ればいいのでしょう。

## 先に痩せたい問題

「少し体を絞ってから水着を買おう」

そう思ったことがある人は、きっと少なくありません。気持ちはとても自然です。水着は服よりも体のラインを意識しやすいですし、更衣室やプールサイドを想像すると、急に心が忙しくなります。

でも、よく考えると少し不思議です。運動するための場所へ行く前に、運動後の自分で行こうとしているのです。

未来の自分に受付を任せすぎています。

今の自分が行ける形を探す。プール再開の一歩目は、そこからでよいのだと思います。

## 水着の思い込み

水着と聞くと、体にぴったり沿うものを想像しがちです。

もちろん、そういう水着もあります。泳ぎやすさを優先するなら、体に沿う形は理にかなっています。けれど、ジムのプールで水中ウォーキングをしたい日や、久しぶりに体を動かしたい日には、別の選び方があってもいいはずです。

トップスがふんわりしている。お腹まわりを拾いすぎない。ボトムが短すぎない。胸元や脇が落ち着く。

それだけで、水着に対する緊張は少し変わります。泳ぐ速さより、まずは入口に立てること。大人のフィットネス水着には、そんな役割があります。

## プールは発表会ではない

頭ではわかっているのに、なぜか忘れがちなことがあります。

プールは体型発表会ではありません。

多くの人は、自分の歩くペース、自分の泳ぐ距離、自分のゴーグルの曇りと戦っています。もちろん視線がまったく気にならないわけではありません。でも、こちらが思うほど、周りは私の水着会議に参加していないのです。

それでも気になるなら、気になりにくい水着を選べばいい。これは逃げではなく、続けるための準備です。

## 隠すより始めるために

体型カバーという言葉には、少し後ろ向きな響きがあります。

けれど本当は、行動しやすくするための工夫でもあります。気になる部分が一つ減ると、プールバッグを持つ手が少し軽くなる。更衣室でのためらいが少し短くなる。水に入るまでの時間が少し楽になる。

その少しが、始める人には大事です。

ふんわりしたトップス、めくれにくい仕様、セパレートの着やすさ、帽子付きで準備がまとまりやすいこと。どれも派手な魔法ではありませんが、今の自分をプールまで連れていくには十分頼れる要素です。

## 今の自分で行く作戦

痩せてから行く、という目標は悪くありません。

でも、痩せるために行きたいなら、先に行ける水着を選ぶ方が話は早いかもしれません。完璧な体を用意してからではなく、今の自分が少し安心して動ける形を選ぶ。

水中ウォーキングからでいい。長く泳がなくてもいい。まずは一回、プールに行けたらそれで勝ち。

体型カバータイプのフィットネス水着は、そういう小さな作戦に向いています。体を変える前に、気持ちのハードルを少し下げる。大人の運動再開は、それくらい現実的でちょうどいいのだと思います。
