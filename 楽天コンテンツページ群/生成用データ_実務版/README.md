# 楽天コンテンツページ生成用データ 実務版

このフォルダは、試作用データを本番生成へ持ち込まないために整理した、楽天コンテンツページ生成用の共通ルール一式です。

## 目的

楽天市場のコンテンツページを、以下の目的で作成します。

- SEO流入を増やす
- 商品ページだけでは伝えにくい知識・選び方・生活の悩みを読み物化する
- 読者に役立つ、読み進めたくなる内容にする
- 商品紹介は本文終盤に置き、読み物のテーマから違和感なく移れる文脈を作る

## 基本思想

- セールページではなく、読み物ページとして成立させる。
- 商品と無関係な雑談にはしないが、商品説明だけにも寄せない。
- コラム、教科書、短い物語、本音記事、比較ガイドなど、内容ごとに表現を変える。
- 画像と動画は、文章を読み進めてもらうための編集要素として使う。
- 動画は商品説明ではなく、タイトルバナー直下に置く「動く目次CM」として使う。
- 実写風画像は、指定がない限り参照素材を使わず、ページごとの差別化を優先する。
- イラスト主体コンテンツは、自社の人物イラスト基準を参照し、テイストを揃える。

## フォルダ構成

- `prompts/`
  - 文章、画像、バナー、動画、音楽の生成ルール
- `templates/`
  - 企画案CSV、納品物、楽天パーツ構成のテンプレート
- `custom/`
  - 店舗ごとの画像テイスト、イラスト基準、任意参照素材
  - 共通ルールを他社へ渡す場合は、各社用の `custom/{brand}/` に差し替える
- `scripts/`
  - 今後使う生成スクリプト置き場
- `samples/`
  - 確認用サンプル置き場

## 重要なNG

- `images/` に商品ページ画像を入れない。
- 商品画像を、リンクできない差し込みバナー内へ合成しない。
- 動画内に商品説明、価格、型番、内部指示文を詰め込まない。
- 動画背景に商品画像の引き伸ばし、ぼかし、薄敷きを使わない。
- 「今日の目次」は使わない。
- 横帯、白帯、黒帯、大きな透過パネルに依存しない。
