# 楽天コンテンツページ群

このフォルダは、楽天市場向けコンテンツページの納品・量産管理用です。

## 納品済みページ

- `001_尿漏れが気になる女性へ_吸水ショーツの選び方/`

## 共通データ

- `共通データ/`: 量産時に使うプロンプト、テンプレート、標準スクリプト

## 1ページごとの基本構成

- `納品用/content_page_completed.html`: RMS貼り付け用の完成HTML
- `納品用/images/`: 本文用のメイン画像
- `納品用/banners/`: 本文途中に差し込むバナー
- `納品用/video/`: BGM付き動画と確認プレビュー
- `納品用/product_images/`: 動画や商品紹介で使った指定商品画像
- `納品用/upload_guide.md`: アップロード手順

## 動画の標準ライン

- 1000px正方形
- 18秒前後
- 冒頭にコンテンツページタイトル
- アパレル寄りの明朝フォント
- 商品画像は中央に1枚ずつ浮かばせる
- BGM付き
- BGMはジャンルごとに生成音源を切り替える
- 説明を詰め込みすぎず、ページの目次・世界観として見せる
- 商品表示シーン以外は、1シーンごとに専用背景画像を生成する
- 同じ背景を使う場合は連続させない。連続使用時はパンやスクロールを固定し、文字アニメーションだけを変える

## バナーの標準ライン

- 横長 1600px × 520px
- 文章ブロック3から5個ごとに1枚
- 生成背景に正確な日本語テキストを後入れ
- 悩み共感、吸水量早見、素材感、商品誘導、CTAを基本にする

## 次工程

楽天市場の所属カテゴリCSVを受け取り、カテゴリ・商品群・利益率・売上傾向を見ながら、コンテンツページタイトル候補を約300件作成する。

## 共通データの使い方

新規ページを作るときは、まず `共通データ/templates/page_structure_template.md` でページ構成を決める。

動画背景は `共通データ/prompts/video_scene_image_prompts.md`、差し込みバナーは `共通データ/prompts/banner_background_prompts.md` を使う。

BGMは `共通データ/prompts/music_style_rules.md` を見て、ページジャンルに合う `MUSIC_STYLE` を選ぶ。

動画やバナーの生成スクリプトは `共通データ/scripts/` からページ固有フォルダへコピーし、文言・画像フォルダ・商品コードだけ差し替えて使う。
