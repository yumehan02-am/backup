# 共通データ

楽天コンテンツページを追加作成するときに共通で使う制作キットです。

## フォルダ構成

- `prompts/`: 画像・動画・バナー生成に使う共通プロンプト
- `templates/`: ページ構成、動画構成、納品フォルダ構成のテンプレート
- `scripts/`: 量産時に流用する標準スクリプト

## 現在の標準ライン

- コンテンツページは「読み物 + 商品紹介 + SEO」を目的にする。
- 動画はページ内容と連動した目次・世界観動画として作る。
- 動画生成時にBGMも同時に生成する。
- BGMはジャンル別プロファイルから選ぶ。
- 動画は商品表示シーン以外、1シーンごとに専用背景画像を生成する。
- 商品画像は中央に1枚ずつ浮かばせる。
- バナーは本文の離脱防止として、3から5ブロックごとに差し込む。
- 日本語テキストは画像生成に任せず、後から正確に合成する。

## 新規ページ作成時の流れ

1. CSVから対象商品・商品群・カテゴリを確認する。
2. コンテンツページのタイトルと検索意図を決める。
3. `templates/page_structure_template.md` をもとに本文構成を作る。
4. `prompts/video_scene_image_prompts.md` をもとにシーン背景を生成する。
5. `prompts/banner_background_prompts.md` をもとに差し込みバナー背景を生成する。
6. 商品画像を指定またはCSVから抽出する。
7. `prompts/music_style_rules.md` をもとにBGMスタイルを選ぶ。
8. 標準動画スクリプトでBGM付き動画を作る。
9. 完成HTML・画像・バナー・動画を各ページの `納品用` にまとめる。
