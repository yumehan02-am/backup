# 在庫転記ツール Version 2

このフォルダは、現行の在庫転記ツールから分岐した Version 2 の作業場所です。

## 目的

現行ツールで蓄積した機能を残しつつ、会社・部署ごとに異なるルールを差し替えられるようにします。

最初に分離する対象は以下です。

- 受注CSV読込ルール
- Excel在庫表の書き込み候補検出ルール

## 現行版との違い

- `037在庫転記ツール` は現行版として残します。
- `037在庫転記ツール_v2` は今後のプロファイル化検証用です。
- DBも別フォルダ内に複製しているため、v2側の変更は現行版DBへ直接影響しません。

## 起動ファイル

```text
inventory_transfer_app_v2.py
```
