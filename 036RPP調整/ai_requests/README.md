# RPP AI作業依頼フォルダ

このフォルダは、AIにRPP調整案を作らせるための依頼セット置き場です。

## 使い方

1. `input` フォルダに分析させたいCSVや資料を入れる。
2. `prompt.txt` の内容を別チャットへ貼り付ける。
3. AIに「このプロンプトを実行して」と依頼する。
4. 作成された作業状態JSONを `../work_states` に保存する。
5. RPP調整ツールの設定画面から、作業状態を読み込んで確認する。

## input に入れる想定ファイル

- RPP実績CSV
- CPC設定CSV
- 除外商品CSV
- 商品CSV
- 店舗の商品別売上実績CSV
  - 例: `202606_Item_SalesList.csv`
- 楽天サーチの流入改善キーワードCSV
  - 例: `act_20260701_20260721_203612.csv`
  - 現在の流入キーワードの参考データとして使います。
- 重点的に売りたい商品のメモ
  - ツール上の重点チェックを使うか、CSV/テキストで商品管理番号と理由を入れてください。
- その他、判断材料になるCSVやメモ

## output

AIが分析メモや提案一覧を出す場合の保存先です。

## archive

過去の依頼セットを退避する場所です。
